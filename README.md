# Streamlit Based Data App

## Project Description
This project is a simple web application developed using Python and Streamlit.
It allows users to enter their name and displays a greeting message.

## Features
- Simple and user-friendly interface
- Accepts user input
- Displays a greeting message
- Runs on Streamlit

## Technologies Used
- Python
- Streamlit

## How to Run
1. Install Python.
2. Install Streamlit using:
   pip install streamlit
3. Run the application:
   streamlit run app.py
